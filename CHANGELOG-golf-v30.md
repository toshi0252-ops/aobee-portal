# Golf v0.30

Next-shot club recommendations now use the current lie and trajectory carry capacity instead of fixed distance thresholds. Keep PT on greens and SW in sand; choose the shortest sufficient club elsewhere, or 1W when none can reach. Manual club choices remain available.

The distance control labels non-putts as landing estimates. Trajectory hints show carry percentages and describe high shots as easier to stop, rather than guaranteed to stop.

Validation: 3,960 club-capacity checks across positions and three trajectories, recommendation purity, automatic next-shot selection, unchanged distance physics, real 30m shots with low/standard/high roll ordering, four viewport sizes, rendered screenshots, no browser JavaScript errors. Human difficulty and physical mobile input remain unverified.
