# 旧世代ファイルの保管

`legacy-20261030/` に、現行ポータルから使われない旧ゲーム本体10点と旧カバー4点を保管した。
削除せず、元のバイト列をそのまま保持している。[一覧・元パス・SHA-256](legacy-20261030/manifest.json)で照合できる。

| 区分 | 保管対象 | 現行版 |
|---|---|---|
| GRAND PRIX | v29、v41〜v46のゲーム本体7点 | v47。入口 `games/aobee_grand_prix_v41_portal.html` は現役のため維持 |
| 冒険 | v5.37の本体1点 | v6.4.1のラッパーと本体を維持 |
| 星の神殿 | v0.20、v0.30の本体2点 | `games/aobee_star_temple_portal.html` を維持 |
| 旧カバー | `race.jpg/.webp`、`yabou.jpg/.webp` | `race-v2.jpg/.webp`、`yabou-gunsei-v1.jpg/.webp` を維持 |

## 旧URLと復元

旧ゲーム本体の元URLには小さな移動ページを残し、対応する現行版を開く。ブックマークから404になることを防ぐ。
旧カバーは公開一覧からの参照がないため、移動ページは置かない。

保管したHTMLは相対参照も原本のまま。archive内での直接プレイは保証しない。
過去版を調査・再現するときは、別チェックアウトでmanifestの `original` パスへ戻して使う。
過去版のGP検証ツールとv47 builderの入力先は保管場所へ更新した。v44〜v46の過去builderは現行入口も書き換えるため、現行公開ブランチでは実行せず、再現用チェックアウトで使う。

## 今後の隔離条件

ポータル・ラッパー・ゲーム内の静的参照と動的なファイル名指定を確認し、現行素材を巻き込まないこと。
例：`assets/gp-connection-diagnostics-v46.js` は現在のGP v47も使うため隔離していない。
歴史資料の旧パスや旧仕様は過去の記録として残し、現在の所在はこの目次とmanifestで補う。
