# あおびー大作RPG 第1章 企画書（試作版）

作成: 2026-11-12 / 作成者: Muse（としとの共同制作）
状態: 企画段階。第1章プロトタイプを作り、としが葵版と比較判定してから本制作に進む。

---

## 1. 作品（仮題）

**『あおびーと失われた歯車』（仮）**
- ジャンル: 明るいコメディ寄りの冒険RPG（ブラウザ、スマホ対応）
- 1章 = 15〜20分で遊び切れる短編章立て。全章で1本の大作にする
- 舞台: 歯車で動く小さな世界。村の中心にある「大歯車」が止まると、時計も水車もパン屋の窯も止まる

## 2. 葵版との差別化（正面からぶつからない）

実コードを読んだ上での葵版『あおびーRPG ～星を忘れた世界～』（STELLARIA）の実像:

| 項目 | 葵版（実測・コード確認済み） | 本作（Muse版） |
|---|---|---|
| テーマ | 星と記憶。「忘れられることと、存在しなかったことは違う」文学寄り | 歯車と騒動。止まった世界を動かし直す、明るい冒険 |
| 序盤 | 序章は村のおつかい3件中2件 → ペンダント探し → ルミナ失踪 | **開始3分で事件発生**。おつかい序章はやらない |
| 初戦闘 | 第1章中盤、リーフィと出会った後の「まよいモコ」戦 | **開始5分以内**にチュートリアル戦 |
| わるびー登場 | 第1章の終盤、星の祠でようやく登場 | **オープニングで登場**し、章ボスとして対決 |
| あおびーの性格 | 優しく素直な相棒役（「星を覚えている小さな友達」） | 主人公。生意気・押しに弱い・口癖を前面に出す |
| 構造 | 序章+全6章+クリア後の長編、通しプレイ未確認（README表記） | 章ごとに完成・公開。1章ずつ実プレイ検証してから次へ |

狙い: 葵版の良さ（丁寧な会話・世界観・完結した物語）は尊重し、土俵を変える。
勝負するのは「序盤のフックの速さ」「主人公のキャラ立ち」「1章単位の完成度」。

## 3. デザインの柱（面白さの判定基準）

1. **3分で事件、5分で戦闘、15分でボス** — 待ち時間を構造から排除する
2. **選択肢で性格が出る** — 会話の選択で「強がる／押し切られる」が分岐し、セリフと小イベントが変わる
3. **わるびーは毎章出るライバル** — 悪役ではなく「先に宝をかっさらう競争相手」。負け台詞と勝ち台詞を毎回用意
4. **既存16本の世界と地続き** — 牧場・釣り・神殿などを後の章の舞台にし、大作感を作る（第1章では匂わせのみ）
5. **章ごとに遊び切れる** — セーブは章単位＋マップ切替時オート。スマホで片手でも進められる

## 4. 登場キャラクター

- **あおびー**: 主人公。公式デザイン厳守（頭に直接の黄色い星、歯車形の尻尾、青い蝶ネクタイ＋中央は黄色い歯車）。口癖「あおびーに任せてよ！」「……仕様です」
- **わるびー**: ライバル。公式デザイン厳守（ダークチャコール、垂れ耳先マゼンタ、欠けたマゼンタの星を直接、銀の歯車の目と蝶ネクタイ中央の銀歯車、牙）。大歯車を持ち去るが、理由は第1章では明かさない（「ふ、ふっ…負けないよ？」）
- **ガルド**（葵版から続投させるかは要判断）: 機械職人。歯車テーマとの相性が最良で、村の工房の主として登場させると既存ファンにも伝わる。続投しない場合は同役の新NPCを作る
- 村人2〜3名: 名前と一言セリフだけの軽い配置（作り込み過ぎて序盤を重くしない）

## 5. 第1章「止まった村と歯車泥棒」ビートシート

想定プレイ時間 15〜20分。

| 時間目安 | 場面 | 内容 |
|---|---|---|
| 0:00 | オープニング | 朝の村。大歯車が止まる音。時計・水車・窯が一斉に止まり村が騒ぎ出す |
| 0:30 | わるびー登場 | 屋根の上で大歯車を抱えたわるびーと初対面。「これは仕様です」と言い逃れするあおびー、村人に押されて追跡を押し付けられる（押しに弱さの初披露） |
| 2:00 | 工房 | ガルドから「追跡用ブーツ（ダッシュ）」と基本操作を30秒で習得。道具は1つだけ |
| 3:30 | 追跡マップ | 足跡（歯車の欠片）を拾いながら進む。欠片3つでわるびーの居場所が分かる。寄り道で隠し欠片+1 |
| 5:00 | 初戦闘 | 行く手をふさぐ「サビつきコグ（歯車の魔物）」とチュートリアル戦。攻撃・歯車スキル（溜めて放つ）・回復アイテムの3つだけを教える |
| 8:00 | 中間イベント | わるびーを追い詰めるが、川の橋の歯車も外されていて渡れない。近くの水車小屋で小歯車を回収する軽い探索＋戦闘1回 |
| 12:00 | 対決前会話 | 選択肢分岐: 「歯車を返せ！」と強がる／「半分でいいから…」と下手に出る。どちらでも戦闘になるが、ボスの初手とセリフが変わる |
| 13:00 | 章ボス戦 | わるびー＆からくり人形戦。ボスは3ターンごとに歯車を付け替えて弱点（星／歯車スキル）が入れ替わる。HP半分でイベント、わるびーは大歯車を置いて逃げる |
| 17:00 | 章エンディング | 大歯車が戻り村が動き出す。ただし歯車は1枚欠けたまま → 第2章への引き。クリア画面で「隠し欠片 ○/4」「選択の記録」を表示して周回動機を作る |

## 6. 戦闘システム（第1章の範囲）

- コマンド式・1対多ではなく最大3体まで。テンポ優先で演出は短く
- あおびーの固有技「歯車チャージ」: 1ターン溜めると次ターン大ダメージ＋相手の歯車を1つ外す（ボスの弱点切替と噛み合わせる）
- 「強がりゲージ」: 会話選択と戦闘中の被弾で上下。満タンで1回だけ自動で踏みとどまる（押しに弱いのに意地っ張り、をシステム化）
- 敗北時は村の工房に戻るだけ（ゲームオーバー画面で時間を使わせない）

## 7. マップ（第1章は3枚だけ）

1. はぐるま村（広場・工房・パン屋。NPC配置のみ、建物内は工房だけ）
2. 欠片の小道（追跡マップ。縦長一本道＋寄り道1つ）
3. 水車小屋と橋（探索＋ボス戦場）

## 8. 制作方式（技術的な約束）

- 置き場所: aobee-portal リポジトリ内に新規フォルダ（例 `games/grand/`）。既存RPGには触らない
- 構成: 既存RPGと同じく `index.html`＋`src/*.js` の小ファイル分割（1ファイル128KB制限を回避し、PR単位で直せる形を維持）
- 進め方: ブランチ＋PR＋プレビュー実プレイ確認 → とし判定 → マージ、の既存フロー通り
- 素材: キャラ絵は公式デザインの既存素材を流用。新規生成が必要な場合は「あおびーゲームス」スレ側で扱う

## 9. 判定ゲート（ここで「葵より面白いか」を決める）

第1章プロトタイプ完成時に、としが以下5項目を葵版序盤と比べて判定する。
3項目以上で勝てていなければ、本制作に進まず作り直し又は中止。

1. 開始5分の引き込み（事件・戦闘までの速さ）
2. あおびーのセリフの面白さ・キャラ立ち
3. 戦闘の手応え（歯車チャージと弱点切替）
4. わるびーとの対決の記憶残り具合
5. 第2章を遊びたいと思えたか
