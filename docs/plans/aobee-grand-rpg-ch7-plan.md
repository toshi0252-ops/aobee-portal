## 1. 第7章「港町と灯台守」

- 位置づけ: 後半戦の入り口。釣りと聞き込みで港の人間関係を作り、灯台へ向かうための「試練」を通る章。
- 舞台: 港町（新規マップ: 町の通り＋桟橋。魚市場と船着き場のある小さな港町）。
- 目玉ギミック: 釣り（内蔵軽量版。タイミングバーで釣る1〜2分の小イベント）。
- プレイ時間: 約2時間（プロットの目標値）。

## 2. ビートシート

1. **導入**: 第6章クリア後、星歯の気配を追って港町へ。灯台の回転歯車が止まり、船が出せず町が困っている、という事情を聞く。
2. **渡し守・源造との出会い**: 渡し守の老人・源造（新規・仮名）に会う。「大物を釣ってきたら灯台へ案内する」と試される。灯台守は高齢で、灯台の鍵の在りかも含めて一筋縄ではいかない、という話を聞く。
3. **必須クエスト「渡し守の試練」**: まず港の小物釣りで腕を見せる（釣り軽量版の導入）。漁師たちの頼みを聞きながら「港の主」と呼ばれる大魚の噂を集める。灯台守の小屋が何者かに荒らされた形跡（＝からくりの仕業）も見つける。
4. **聞き込みと痕跡**: 魚市場の女将・とめ（新規・仮名）や漁師の若手・海斗（新規・仮名）から話を集める。港に残された、失敗した自動魚獲り機の残骸を見つける。部品には村の工房と同じ刻印がある（＝わるびーの痕跡）。ここで「本当に悪人か？」の揺れを、断定せずに置く。
5. **サブクエスト（任意）**: 海斗の折れた竿の材料集め（流木3本）。報酬は第8章の釣り勝負での支援＝大物の弱点ヒント。
6. **締め**: 港の主が姿を現した報せ。桟橋が騒ぎになり、第8章の釣り勝負へ。章末、郵便屋テルが「わるびーからの挑戦状」を届ける（第1章でテルの雑談に仕込んだ「わるびーから預かった手紙」の伏線回収の始まり）。

## 4. システム追加（エンジン拡張）

- **釣り（軽量版）**: タイミングバーで釣る1〜2分の小イベント。成功で小物が釣れる。失敗しても詰みなし（やり直し可）。第8章の釣り勝負の土台になるため、操作感は第8章と共通化する。
- **聞き込みフラグ**: 漁師たちの頼み・噂を集める進捗管理。源造の試練の合格条件は「小物釣りの成功＋噂集めの一定数」とする（具体的な数は実装時に決める）。
- **流木集め**: マップ上の流木3本を拾うサブクエスト。報酬は第8章への持ち越しフラグ（大物の弱点ヒント）。
- **章開始導線**: 第6章クリア画面に「第7章へすすむ」を追加。セーブ移行は既存方式。章タイトルカード（約1.75秒）は「第7章 港町と灯台守」で全継ぎ目と同じ仕組みを使う。
- **レベル上限**: 現行Lv5上限は3章分までの試作仕様で、プロットでは神殿編クリアでLv8を目安としている。カニコグ×3だけでは上げ幅が小さいため、上限を7〜8へ広げるかは実装時のバランス検証で判断する（決め打ちしない）。
- **元ネタリンク**: 第7章クリア画面に釣りゲーム（フィッシング）へのリンクを入れるかは未決定。第2・3章方式の踏襲だが、章末が第8章への直結のため、リンクの置き場所は実装時に決める。

## 8. 実装メモ（2026-11-20、実装時に確定した事項）

- 釣り軽量版: タイミングバー方式。当たりゾーンは開始位置45〜79%のランダム、幅18%。失敗してもペナルティなし・即リトライ可。止める操作はボタン／タップ（grand-tapa連動）。
- レベル上限: 本章では現行のLv5のまま据え置き（カニコグ exp20×3＋再入場復活で稼げるが上限到達済みの場合は伸びない）。上限拡張は第8章のボスバランスと合わせて判断する。
- 元ネタリンク: 第7章クリア画面に釣りゲーム（aobee_pico_fishing_v68_portal.html）へのリンクを配置。
- 章末の締め: 港の主の出現＋テルの挑戦状配達までを一連の会話イベントとし、第7章クリア画面を出す（偶数章ボス撃破時のクリア画面パターンを町の章にも適用した形）。
- マップは2枚（港町の通り／桟橋）。灯台守の小屋は通りの西の建物として配置し、内部には入らない（第8章の灯台と合わせて扱う）。
