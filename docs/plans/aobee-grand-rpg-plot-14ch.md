## 1. 全体設計

- **構成**: 全14章＋エピローグ。舞台ごとに「町の章（人・事件・必須クエスト）」＋「決戦の章（ダンジョン・ボス）」の2章構成
- **テーマ**: 「意地と素直さ」。強がるあおびーと、負けを認められないわるびー。意地っ張り同士の物語
- **物語の芯**: わるびーは世界各地の「要の歯車」から歯（星歯）を抜き集め、自分の発明「わるびータワー」を完成させて世界一の発明家を名乗ろうとしている。あおびーは各地を回って星歯を取り戻し、最後にタワーの頂上で決着をつける
- **星歯は全7枚**。内訳は下の対応表のとおり。はぐるま村の大歯車から抜かれた歯が7枚目で、タワーの心臓に組み込まれている（第6章の伝承で判明）
- **わるびーの本音（最終章で全開示）**: 昔、村で歯車の発明を笑われた。「見返してやる」という意地だけでここまで来た。悪人ではなく、認められたいだけの意地っ張り
- **戦闘**: あおびー単独＋章ゲストNPCの支援（パーティ編成なし）
- **ギミック**: 各舞台の元ゲームの遊びを1つだけ借りる。ミニゲームはRPG内蔵の軽量版（1〜2分）＋章クリア画面に元ネタへのリンク

### わるびーの動機の開示段階

| 段階 | 章 | プレイヤーが知ること |
|---|---|---|
| 謎 | 第1〜4章 | 歯を集めている理由は不明。ただの意地悪に見える |
| 目的判明 | 第5〜6章 | 伝承で「タワーを作っている」と分かる |
| 痕跡 | 第7〜8章 | 失敗した発明の残骸、村への仕送りの痕跡。「本当に悪人か？」と揺れ始める |

| 全開示 | 第13〜14章 | 「発明を笑われた意地」の全貌。あおびーの「素直に頼む」で回収 |

## 2. はぐるま村編

### 第1章「はぐるま村と歯車泥棒」（町の章）★大半は実装済み

- **舞台**: はぐるま村、村はずれの森
- **流れ**:
  1. オープニング。村の大歯車が止まった朝。屋根の上で大歯車を掲げるわるびーを目撃（一枚絵カットシーン）。「ふ、ふっ…負けないよ？」の初登場
  2. 工房のガルドからダッシュブーツを受け取り、村の人々と出会う（パン屋のマーミ、子どものポコ、村長ダイジ、薬屋ハル婆、郵便屋テル）
  3. 村長ダイジの必須クエスト「丈夫な歯車」: 水車小屋の橋を直すには丈夫な歯車が要る。村はずれの森の祠を荒らす中ボス「オオコグ」を倒して取り戻し、ガルドへ納品
  4. 章の締め: 橋の修理が始まり、小道の先への道が開く（第2章へ）
- **登場人物**: あおびー、わるびー、ガルド、マーミ、ポコ、村長ダイジ（新規・眼鏡フクロウ）、薬屋ハル婆（新規・モグラ、回復スポット兼任）、郵便屋テル（新規・ハト）
- **ギミック**: なし（基本操作と世界の紹介が役目）
- **レベル上げの土壌**: 森のもりコグ×3（再入場で復活）
- **サブクエスト**: マーミの焼きたてパン配達（村長へ／報酬ほし草+1）、ハル婆の薬草集め（森の光る草3か所／報酬ほし草+2）
- **伏線**: 村長の雑談「わるびーも昔はこの村の子」（→第11〜12章で回収）。テルの雑談「わるびーから預かった手紙がある」（→第7〜10章の挑戦状で回収）
- **想定時間**: 約1時間10分（実装済み分の実測寄り）

### 第2章「水車小屋とコグの巣」（決戦の章）★実装済み

- **舞台**: 欠片の小道、水車小屋と橋
- **流れ**:
  1. 小道で歯車の欠片を3つ集める（初戦闘）。東エリアの番人まわりコグが見える敵として立ちはだかる
  2. 水車小屋。水車を止めているコグの巣3つを壊す（必須クエスト。巣は見える敵）
  3. 小歯車をはめて橋を開通。橋の向こうでわるびーと対面し、ボス「からくり人形」と対決
  4. 大歯車を取り戻すが、歯は1枚欠けたまま。ガルドの「その歯、ただの歯やないかもしれん」で幕
- **ボス**: からくり人形（弱点切替＋強がりゲージ。第1章ボスの型）
- **サブクエスト**: ポコの木の剣（小道の落とし物／報酬ほし草+1）
- **回収**: 大歯車（歯1枚欠け）。※この欠けた歯こそ星歯7枚目だと第6章で判明する
- **想定時間**: 約50分（実装済み分の実測寄り）

## 3. 牧場編

- **ボス**: ホシガミさま（明暗フェーズ。実装済み）
- **サブクエスト**: ミオのお守り（神殿の暗闇に落ちている。灯りの範囲で探す／報酬ほし草+2）

## 6. サーキット編（元ゲーム: GP）

### 第10章「歯車サーキットの挑戦状」（決戦の章）☆新規
