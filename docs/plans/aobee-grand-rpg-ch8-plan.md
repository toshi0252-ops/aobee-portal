## 1. 舞台・マップ

### 灯台内部（新規・20×14）
- 螺旋階段を折り返しで登る一本道マップ。石床（_）＋石壁（W）の神殿系タイルで統一
- 仕掛け: 中腹に歯車扉（レバーを調べると開く、水車小屋の橋ゲートと同方式）
- 見える敵: うずコグ×2（新規の雑魚。HP40/atk9/exp26、再入場で復活）
- 入口は桟橋の東端（岩場の小道）から。源造から鍵を預かる前は入れない

### 灯室（新規・20×14）
- 頂上の円形の間。中央に灯りの装置（大きな歯車＋レンズ）
- ボス「タコぐるま」との決戦場。撃破後は灯りが戻り、装置が光る演出（タイル差し替え＋会話）

## 3. 流れ（クエスト）

1. **章開始**: 桟橋に「港の主が現れた」と源造。釣り勝負のイベント戦へ
2. **釣り勝負**: 第7章の釣り軽量版を流用した一発勝負（ゾーンは少し狭く・速く）。成功で大物を釣り上げる→正体はタコぐるまの囮からくり。本物が姿を現して墨を吐き、灯台へ逃げ込む
   - 失敗してもペナルティなし・即リトライ可（従来方針）
3. **灯台の鍵**: 源造から鍵を預かり（lighthouseKey）、桟橋の東端から灯台へ
4. **灯台登り**: うずコグ×2＋歯車扉のレバー。道中の壁に「失敗した発明の残骸」と、村への仕送りの控え（調べるスポット／痕跡段階の開示）
5. **ボス「タコぐるま」**: 複合フェーズ（2ターンごとに切替）
   - **歯車フェーズ**: 背びれが開く。歯車攻撃（ギアタック系＝従来の weakMode 'gear'）が有効で、1ヒットごとに背びれの歯車が1つ外れる（全3つ）
   - **墨フェーズ**: 墨を吐いて視界を奪う。通常攻撃は半減、歯車は狙えない（weakMode 'ink'）
   - 歯車を3つ外すと本体がむき出しになり、全フェーズ通常弱点化＋防御低下
   - 海斗のヒントを聞いている（driftDone）場合は、戦闘前にあおびーが弱点を言い当て、初手が歯車フェーズから始まる。未取得の場合は源造が鍵と一緒に助言する（詰み回避）
   - 目安: HP140 / atk9 / exp90（実装時の自動プレイ検証で、初見でも届く塩梅に調整）
6. **決着**: 星歯3枚目を回収。灯室の装置に星歯がはまり、灯台に灯りが戻る。港では船が出せるように
7. **章の締め**: テルの挑戦状の文面が開く——「歯車サーキットで待つ」。第8章クリア画面（次章予告つき）

## 4. レベル上限の拡張

- EXP_THRESHOLDS を [0, 30, 75, 140, 230] → **[0, 30, 75, 140, 230, 350, 500, 690]**（Lv8まで）

- 章開始時の会話で「星歯の共鳴であおびーの力が戻ってきた」と理由づけし、上限アップを明示する
