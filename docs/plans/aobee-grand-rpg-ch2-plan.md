## 1. 第2章「暴走！ まきばの大風車」

- 舞台: はぐるま村の西隣「星のしずく牧場」と、村と牧場を繋ぐ「まきばの道」
- 元ネタ: ポータルの牧場ゲーム。舞台・雰囲気は元ゲーム準拠、遊びは内蔵の軽量版（2026-11-13決定の方針通り）
- 想定プレイ時間: 15〜20分（第1章クリア済みのプレイヤーが続けて遊ぶ前提）
- この章の役割: ①物語のスケールを村の外へ広げる ②「歯車を外して止める」戦闘の発展形を出す ③星歯の存在をプレイヤーに目撃させる

## 3. 新規キャラクター・敵

- **みのりさん**（元ゲームから続投）: 星のしずく牧場の牧場主で、元の牧場ゲームの指導役のお姉さん（「作物は毎日の積み重ね。焦らず育ててね」）。優しく穏やかな口調で、あおびーに動物集めを柔らかく頼む役回り（それでも断れない、で「押しに弱い」を出す）。見た目（麦わら帽子＋作業着）は今回の新規イラストで起こす
- **クワコグ**（雑魚）: 鍬を持った農機コグ。まきばの道と牧場に出現
- **モーぐるマシン**（章ボス）: ウシ型の自動収穫機。大きな歯車が3つ露出している。止める対象であって倒す対象ではない、という戦闘の読み替えが肝
- 動物（ウシ・ヒツジ・ニワトリ）: 戦闘には出ない。誘導ギミック専用のマップキャラクター

## 4. システム追加（エンジン拡張）

1. **章の概念**: セーブに `chapter` を追加。第1章クリア画面に「第2章へすすむ」を追加し、タイトルの「つづきから」は現在の章・マップから再開する。旧セーブ（第1章クリア済み）からは第2章の冒頭を開始できること
2. **星歯カウンタ**: セーブとHUD/クリア画面に「星歯 n/7」を追加
3. **動物誘導ギミック**: 動物はプレイヤーが隣接すると反対方向へ1マス逃げる。柵エリア内に入ったら捕獲（固定表示＋カウント）。シンプルで詰まない設計に（逃げ場がなくなる配置にしない）
4. **ボスの「歯車を外す」勝利条件**: 戦闘に HP 以外の勝利条件を持てるようにする（対象はモーぐるマシンのみ。通常攻撃は小ダメージ＋セリフでヒント、チャージ攻撃命中で歯車カウント+1、3で勝利）
5. **元ネタリンク**: 第2章クリア画面に、ポータルの牧場ゲームへの相対リンクを置く（リンク先パスはリポジトリの index.html で実在確認してから使う。推測で書かない）
