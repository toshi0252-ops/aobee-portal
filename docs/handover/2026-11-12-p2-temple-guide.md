# P2 星の神殿 序盤案内の親切化（2026-11-12）

対象: `games/aobee_star_temple_portal.html`
監査P2「牧場・RPG・神殿の序盤案内の親切化」のうち神殿分。実プレイ診断（2026-11-12、本番版）で確定した所見に基づく。

## 診断で確定した問題
1. 会話の条件（NPCの隣に立つ＋相手のほうを向く＋Space/調べる）が、タイトル・導入・メニューのどこにも説明されていない。失敗時は「何もないみたい」のトーストのみで、距離・向きへのヒントがない。タップでは隣接していても会話できない。
2. クエスト手がかり「足跡」のラベルが、輪郭なしの淡いクリーム色（#e5cf9e）で明るい石畳の上に直接描かれ、足跡の楕円も同系色で、等倍では判読しづらい。NPC名などは紺地プレート付きで高コントラストなのと対照的。

## 修正内容（3点、いずれも案内・視認性のみ。判定や会話ロジックは無変更）
1. **タイトル画面に話しかけ方を1行追加**: 既存の操作行の下に「話しかけ方：相手の隣に立って、相手のほうを向いてから「調べる（Space）」」を表示（既存の small 挿入処理の直後に1文追加）。
2. **失敗時のヒント（末尾に新レイヤー追加）**: 既存の `action`（s105までの全レイヤー適用済み）をラップし、「村エリアで、会話が開かず、NPCの隣（上下左右1マス）に立っている」場合にだけ、元の「何もないみたい」に代えて「相手のほうを向いて話しかけてみよう。隣に立って、向きを合わせるのがコツだよ。」とトースト表示する。開始画面・終了後・会話中は発火しない。
3. **足跡の視認性**: 足跡の楕円の色を #e5cf9e → #caa96d に濃くし、「足跡」ラベルに濃茶（#3d2c17）の縁取り（strokeText、lineWidth 3）を追加して文字色も #ffeec2 に変更。描画位置・表示条件（クエスト進行で消える仕様）はそのまま。

## 直していないもの
- 「橋」「低木」ラベルも同じ淡色スタイルだが、監査の指摘は「足跡」のため対象外とした（同方式で改善可能）。
- PC移動が小文字wasdのみ有効（大文字WASDは無反応）なのは実プレイ診断で見つけた別件の不具合。タイトル表記「WASD」と食い違うが、本PRの範囲（序盤案内）とは別として報告のみ。
- 移動テンポの遅さ（監査所見）もゲーム感覚の調整になるため対象外。
