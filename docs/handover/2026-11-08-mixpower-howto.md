# 連携資料: MIX POWER 遊び方・消去条件の明示（2026-11-08、Muse）

## 背景（遊戯監査 P0-2）

消去条件「同じマークを4つ以上つなげる」はコード上正常に実装されている（findMatches: group.length>=4）。問題は伝わり方:

- ルール文はタイトル画像の「遊び方」ホットスポット裏のモーダルにしかなく、GAME START から始める初見は目にしない
- ゲーム開始オーバーレイの文言は「つないで、消して、FLOWを狙え！」で、肝心の「4つ」が書かれていない
- プレイ中のサイドカードに「4個つなげて消去」とはあるが小さく、監査の実プレイ（17ピース落下・消去ゼロ）でも認知されなかった

つまり「説明が存在しない」のではなく「初見の導線に乗っていない」。そこを直す。

## 変更内容（games/AOBEE_MIX_POWER_v2.32_4GAUGE.html）

1. **常時表示のルール行**: メッセージ行（#msg）の直下に `.rule-line` を追加し、プレイ中ずっと「同じマークを **4つ** つなげると消えるよ！ 金の輪 = あと1つで消える」を表示。レイアウトは通常フローへの1行追加のみで、盤面・オーバーレイの位置には干渉しない。
2. **「あと1つ」ヒント（金の輪）**: render() に `hintCells()` を追加。既存の collectGroup / neighbors を再利用して接続グループを数え、**ちょうど3個**つながっているグループのピースに `hint3` クラスを付け、`.orb.hint3 .token` の金の輪（box-shadow）で表示。4個以上（消去対象）・2個以下・お邪魔（GARBAGE）は対象外。落下中のペアは対象外（確定した盤面のみ）。
3. **開始オーバーレイの文言**: 「つないで、消して、FLOWを狙え！」→「同じマークを4つつなげると消えるよ！／消えたあとの連鎖がFLOW！」に変更。

## 対象外

- 遊び方モーダル（タイトル画面）の中身・導線は無変更（詳しい説明は従来どおりそちら）。
- 消去判定・落下・スコア・FLOW/MIX技などのゲームロジックは一切無変更。変更は表示のみ。

## 検証

- 編集後のインラインスクリプトを node --check で構文検証済み。
- hintCells のロジックは、本体から抽出した実関数（neighbors / collectGroup / hintCells）で単体テスト済み: 3個グループのみ抽出、4個グループ除外、お邪魔3個除外、L字（縦横接続）抽出・斜め不接続、2個除外 — 全件パス。
- プレビュー（raw.githack 経由のブランチ版）で表示確認: ルール行の表示、開始〜プレイの動作、可能なら3個グループの金の輪を目視（結果は PR に追記）。
