# 探索の成長: ハートのかけらと風のブーメラン

玲奈 / 2026-11-17

ユーザー要望: HPが3固定/武器が初期3種だけで、探索で新しい能力が増えない。ブーメラン用の仕掛けと新イベントも追加してよいとの指示。

## 新要素
- 各章4個、合計20個のハートのかけら。4個ごと最大HP+1、3→8。小箱・寄り道・既存の任意依頼のお礼・各地の星門に配置。手帳で章別進捗と未発見の場所を確認。
- 森の南西(9,13)の古い旅人の小箱。旅日記の導入会話を読み終えて風のブーメランを入手。B/投げるボタンで投げ、もう一度で呼び戻す。
- 行き帰りで敵を足止め・小ダメージ。同じ投擲で同じ敵に重複命中しない。星のかけら、地図片、ハートのかけらを遠隔回収し、戻ってから受け取る。プレイヤーは瞬間移動しない。
- 星片4→8で2段階強化。射程5→6→7、足止めと威力も増加。

## 4つの寄り道イベント
1. 森・東の風の祠: 風車に当てて隠れた小箱を発見。同じ投擲で奥のハートを持ち帰れる。
2. 2章水辺: 対岸のレバーを回して東の跳ね橋を下ろす。飛行は水路越しに通り、歩行は橋が下りてから通る。既存の道も維持。
3. 3章防波堤: 荷揚げ風車を回すと吊り荷が下りる。海鳥/クレーンの描画とイベント会話。
4. 4章図書塔: 手前と奥の風見栞を一投で回す。別々の投擲では解けない。
本編の必須条件は増やさない。既クリアでも回収・解決可能。

## 保存・互換と表示
- adventure.version=1 に取得ID、道具、強化、仕掛けを保存。既存セーブは初期HP3、未取得から。3スロット/自動/デバッグ前退避に含まれる。
- validSave は既知の取得IDから許可HPを算出し、HP4〜8を正しくロード。回復宝箱・薬・ボス後回復・敗北時回復も最大HPへ対応。
- 飛行中の弾と未配達品は保存しない。移動/ロードで中断しても、未配達品は現地に残る。
- 右端の道具/仕掛けがタッチボタンに隠れないよう横カメラを追従。描画・同行者・エフェクト・名前札を同じ座標へ。新しい小箱/風車も近接案内の選択対象へ。
- デバッグに4地点を追加して計32。各章の新仕掛けをブーメラン入手後の状態で試せる。道具は実際の入手会話を終えたスナップショットから生成。
