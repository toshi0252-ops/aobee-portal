# スマホの中央画面・両手操作へ再構成

玲奈 / 2026-11-18

ユーザーから、右の縦列に移しただけで画面が左寄りになり、人間の操作性とバランスを考えていないと指摘。右側の固定レールを撤去し、操作の頻度と左右の役割から配置を変更。

- ゲームを画面の縦横中央に配置。左右は同じ64px+セーフエリアを基準に確保し、16:9を維持。縦の操作列のために片側へ画面を押し寄せない。
- 左下に移動位置の目印、その上に守る。画面左半分のスライド入力も維持。
- 右下は64pxの主攻撃、その近くに52pxの回避/ブーメランを三角形の範囲に配置。調べるは右上の補助位置。ボタンは44px以上、相互に重ならない。
- 地図/目的/武器持替はメニュー内へ。攻撃ボタンに現在の武器名を小さく表示。右上の常設補助ボタンはメニューだけ。
- 主操作は押した瞬間に反応するようタッチのpointerdownへ。非主ポインターにも対応し、左指で移動中に右指で攻撃できる。合成クリックの二重実行を抑止。PCのクリック/キー操作は維持。
- 下隅の道具ボタンは半透明で、画面の広さも確保。前回の「全ボタンを画面外に置く」条件に固定せず、中心と親指の位置、使用頻度を優先。

検証: temple-mobile-layout.cjsを仕様に沿って書き換え。568x320、667x375、844x390、1024x768で画面中心のずれ1px未満、画面サイズ保持、主/補助の大きさ、親指クラスタ間距離、ボタン非重複、メニュー移動後の地図/目的/持替、投擲/呼び戻し、実CDP二本指で移動+攻撃を確認。各サイズ画像を目視。edge-controls、discoveries-browser（HP4/8保存含む）、action-combat-browser（全6戦）もPASS。JSエラーなし。

旧レール用テストは単に位置を検査しており、左右同時操作の検証が不足していた。今回は同時タッチを追加。セーブ形式と進行は変更しない。
