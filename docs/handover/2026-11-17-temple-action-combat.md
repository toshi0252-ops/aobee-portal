# 戦闘改修: 攻撃・回避・ガード、武器防具と強化

玲奈 / 2026-11-17

ユーザー指摘: ボスは手順待ちばかりで爽快感がなく、雑魚は体当たり、装備の意味も薄い。戦闘モジュール assets/temple-combat.js を追加。既存の章進行と勝利後イベントを保持し、手順による旧ルートも利用可能。

## 操作と仕組み
- 調べると攻撃を分離。スマホは右の攻撃/回避/ガード/持替。PC J/K/L/Q。Spaceは従来の調べる。
- 全6戦（守護機械+1〜5章ボス）を通常攻撃で進められる。閉じた状態も削れる。放出後/崩し中はダメージ増、既存ギミックは加勢になる。HPと連撃、火花、短いヒット停止、効果音（装備で切替）。敵のHPに応じて段階が進む。
- 体勢崩しに耐性時間を設け、ハンマーの永久拘束を防止。直前ガードは弾いて反撃の隙、回避には短い無敵。
- 雑魚の接触ダメージとランダム追跡を止め、予兆付きの突進/射撃/盾持ちへ。森に加え2〜5章の探索地点に配置。町は安全。倒した敵は再ロードでも消えたまま。
- 剣は素早い3連撃で3撃目が強打、槍は3マスの直線、ハンマーは盾割りと強い吹き飛ばし。盾は側面・3連撃・ハンマーで崩せる。
- 防具3種: 旅装は3マス回避、守り手の胴衣は自動1撃防御、星鉄は自動2撃防御だが回避1マス。自動防御は時間で回復。付け替えで使い切った防御を即補充しない。
- 敵から星片2、ボスから6。武器/防具を各2段階まで強化（費用4→8）。武器は威力、防具は回避消費と防御回復時間などに効果。本編の星かけらとは別通貨。

## 保存と互換
combat.version=1 に防具・星片・強化・ボス残HP・各地の敵・音設定を保存。3枠、旧セーブ、デバッグ前退避にもそのまま含まれる。戦闘中の予兆/弾/クールダウンはロード時に安全側へリセット。デバッグ28地点は実フローから再生成。章の completeCombat は既存の勝利処理を呼び、次章/会話/依頼の整合を維持。

## 検証
- temple-action-combat.cjs: 全6戦を攻撃で勝利、閉じた状態で削れること、槍間合い、剣3連撃の盾崩し、弾き、防具2撃、回避無敵と距離、強化費用/上限/保存、雑魚の接触では減らず突進で被弾、射撃の実ダメージ、描画で保存内容を変えない。
- temple-action-combat-browser.cjs: 667x375の実Edgeで全6戦をボタンで勝利、戦利品から強化、防具選択、J/K/Q、飛び道具をガード/弾いて射手をひるませる。攻撃/調べるの接触領域を分離。スクリーンショット目視。
- recovery-browser: 旧ボス前データ、全28地点、3枠、退避/復帰、保存失敗。
- state-consistency、journey-browser、dialogue-browser、edge-controls: 全章進行・33地域・章間移動・スマホ4サイズ。

爽快感や難度の好みは実際のユーザープレイでの調整余地がある。今回の検証は操作・戦闘勝利・状態互換を確認するもの。
