# 途中再開28地点・手動セーブ3枠

玲奈 / 2026-11-17

ユーザーは旧ボス直前セーブで修正が変わらないと報告し、章ごとの途中再開と3スロットを要望。旧セーブはコードを保持しておらず、今回実Edgeで旧ボス直前データをUI経由で読み込み、1マス180msの移動と攻撃で段階2へ進むことを確認した。ユーザー端末で変わらなかった原因は未特定。古いタブ/ページの可能性に備え、更新版表示とセーブを残してキャッシュ回避する再読み込みボタンを追加。

## 使い方
- タイトルまたはメニュー → 途中から・デバッグ → 各地点を選択。
- 1章: 村、森、遺跡、守護者戦前、封印ボス前/後。
- 2章: 結界、三叉路、塔入口、塔1/2/3階、最上階ボス前/後。
- 3章: 港、観測所、灯台、ボス前/後。
- 4章: 入り江、図書塔、貯蔵庫、ボス前/後。
- 5章: 神殿、四つの星門、最終戦前、エンディング前。
- メニュー → セーブ3枠。各枠に手動保存/上書き/ロード。自動セーブは別。タイトルの続きからも同じ選択画面。

## データ保全
- 旧自動セーブキーは維持。初回に手動slot1へコピーする。残りの2枠は空き。
- 手動バンク aobee_temple_manual_slots_v1 は単一JSONとして保存。自動保存は手動3枠を変更しない。
- デバッグ前の通常冒険を aobee_temple_before_debug_v1 に退避。デバッグ地点間を繰り返し移動しても退避元は変更しない。「デバッグ前の冒険に戻る」で復元。
- debugCheckpoint を保存してデバッグ中を識別。ゲーム本編の判定には使わない。
- 退避や保存に失敗したら通知し、元データを変更しない。退避できない場合はデバッグ移動を中止。
- 同一ブラウザ/端末のlocalStorage。クラウド同期はなし。
