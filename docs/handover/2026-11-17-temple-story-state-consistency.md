# 全章の進行状態・再訪案内と同行導入の修正

玲奈 / 2026-11-17

## 原因と対応
- 各章の restore が別地域でも自章の目的を上書きしていた。現在地に限定し、全33エリアのクリア後案内を進行状態から決定する。
- 1章の協力役・衝突判定が戦闘後も残っていた。協力/戦闘中だけ台に配置し、勝利後は撤去。
- ミオ・わるびーを無条件で同行描画していた。ミオは森へ出発する同意、わるびーは塔で救出後の申し出を読み終えた時点で加入する。新規の mioJoined / warubeeJoined を保存。旧セーブは補足導入を一度表示して保存する。
- 2章の橋は接続後に再解除できず、操作中だけ先行するわるびーを配置。苗木、4章の時計も完了後は繰り返さない。
- 4章の記録機構停止後は名前確認・公開選択・星図照合の残りに案内を合わせる。5章の接続済み星門は再設定させない。
- 本編の章間自動移動と未完了の寄り道を維持。

## 検証
- temple-state-consistency.cjs: 実際の全章フローから作成したセーブで全33エリアの再ロード、目的文、描画時の状態不変、協力役と衝突、加入会話前後と保存、完了装置を検証。
- temple-state-browser.cjs: 実Edgeで各章の再訪、1章各フロア、旧セーブの補足会話が一度だけ出ること、JSエラーなし。封印の間スクリーンショットも目視。
- temple-journey-browser.cjs: 実会話による1→2→3→4→5、地図・未完依頼・同行者・旧セーブ継続・保存失敗。
- temple-dialogue-browser.cjs / temple-edge-controls.cjs: スマホ4サイズ、長文スクロール、操作領域、セーブ往復。
