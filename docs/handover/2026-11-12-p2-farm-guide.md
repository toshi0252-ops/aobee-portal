# P2 あおびー牧場 序盤案内の親切化（2026-11-12）

対象: `games/aobee_farm_v48_soil_water.html`（＋ポータルのキャッシュバスター）
監査P2「牧場・RPG・神殿の序盤案内の親切化」のうち牧場分。実プレイ診断（2026-11-12、本番版）で確定した所見に基づく。

## 診断で確定した状況
現行版には既に「次にすること」パネル、下部メッセージ、タイトルの遊び方（初日ガイド）があり、監査時点（2026-11-08）より案内は大幅に改善されていた。そのうえで初見プレイで残っていた摩擦は次の3点。

1. **正面マスの黄色い枠が見落としやすい**: 枠は淡いクリーム色（#fff6c8）の2px線＋ほぼ透明な塗りで、茶色い畑の上ではコントラストが弱い。畑の場所と順序はテキスト頼みになっていた。
2. **ゲーム内ヘルプの説明がUIと食い違う**: 「設定・セーブ」内の遊び方に「道具を選んで『道具を使う』」とあるが、その名前のボタンは画面に存在しない（実際は枠のマスをタップ／「おまかせ作業」）。
3. **道具の順序と「おまかせ」の役割が道具棚で分からない**: 道具は4つ対等に並び、畑タップ時は選んだ道具ではなく「おまかせ」が状態に合わせて選ぶ仕様だが、その説明がなく「自分の選択が無視された」と感じる。

## 修正内容（3点、案内・視認性のみ。作業ロジックは無変更）
1. 正面枠の塗りを濃い琥珀色（#ffc93359）にし、線を #ffb400 の3pxにして、畑の上でも枠が目立つようにした。
2. ゲーム内ヘルプの該当文を実際の操作に合わせて書き換えた（枠の出方→タップ／「おまかせ作業」で 耕す→種まき→水やり の順に進むこと、「道具・種」から自分でも選べること）。
3. 道具棚（「道具・種を選ぶ」の中）に1行追加：「順番は 耕す→種まき→水やり→収穫。畑をタップしたときは「おまかせ作業」が畑の状態に合わせて道具を選びます。」
4. ポータルの牧場リンクのキャッシュバスターを ?v=ui49 → ?v=ui50 に更新（index.html）。

## 反映方法の注意
牧場本体は単一ファイルで約8.4MBあり、GitHub連携ツールの push-files 上限（7.2MBでHTTP 413を確認済み）を超えるため、本体ファイルはブランチへ GitHub Web UI のアップロードで反映した（25MB上限内）。コミット前にローカル編集版とスクリプト全13ブロックの構文チェック済み。反映後はブランチの raw 取得で md5 一致を確認すること。

## 直していないもの
- 「次にすること」パネルが畑の左上・日付表示に重なる点は、レイアウト全体への影響が読めないため対象外とした。
- 道具の手動選択そのものの挙動（タップ時は「おまかせ」優先）はゲーム仕様として変更していない。今回は「説明して納得できる」側で対応。
