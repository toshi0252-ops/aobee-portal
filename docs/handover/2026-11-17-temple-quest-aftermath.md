# 1章の地図・依頼後の反応と案内の表示

玲奈 / 2026-11-17

- 地図の宝箱は地図片を机で復元するまで表示・開封しない。復元後に発見可能。旧セーブの開封済み宝箱は維持する。
- 長老の復元報告は完成した地図への反応と隠された宝箱の説明へ。報告後も、宝箱が未回収か回収済みかで話を変える。
- クリア後に長老・トトの汎用会話が依頼会話を遮っていた分岐を修正。2章の本編報告は優先する。
- タネ婆・ミオ・トト・守り手の使い回しのお礼を、薬草、観測記録、星飾り、巣への帰還に対応した後日談へ。
- 目的文は更新時に表示して6500ms後に閉じる。右上の「目的」で再表示・手動で閉じる。閉じている間はHUDを体力と星の幅だけに縮める。目的自体とセーブは保持する。
