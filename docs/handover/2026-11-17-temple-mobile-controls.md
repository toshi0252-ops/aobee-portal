# スマホの操作欄をゲーム画面から分離

玲奈 / 2026-11-17

ユーザーのブーメラン操作質問と「右下のコマンドがゲームに被ってごちゃつく」指摘に対応。

- 横持ちのタッチ端末（幅1100px以下）では右152px+セーフエリアを操作欄に予約。ゲームは左に16:9で収め、画面へのボタンの重なりをなくす。
- 上段は地図/目的/メニュー。持替（現在の武器名）/投げる/回避・ガード/調べる/攻撃を一定の行に配置。最小44pxの押せる面積。PCキー文字をスマホでは隠し、B表記も投げるボタンから削除。
- 調べるボタンをbodyへ移し、ゲーム側の描画の重なり順で操作欄の裏に隠れる問題を防止。
- 操作欄を触って移動しない。移動は左のプレイ画面を滑らせる。地図などの既存機能は同じボタンで維持。
- スマホでは横カメラを戻して全幅のマップを表示。文字サイズは実際のキャンバス幅を基準にし、縮小で小さくなりすぎないよう対応。
- メニューにスマホ操作ガイドを追加。方向を決める→投げる、再押下で呼び戻し、風車/回収/足止めから追撃を説明。
- セーブ形式・進行・デバッグ32地点は変更なし。

検証: temple-mobile-layout.cjs で568x320、667x375、844x390、1024x768の全9ボタンがゲーム外/互いに非重複/44px以上/画面内。タップ投擲と呼び戻し、操作欄で移動しない、地図/メニュー/ガイド、縦持ち停止、JSエラーなし。目視で調べるを含む全ボタン表示を確認。edge-controls はタッチの右側を移動面から操作欄へ変更した仕様に合わせた。新イベント/HP8保存・全章状態・戦闘も回帰確認。
