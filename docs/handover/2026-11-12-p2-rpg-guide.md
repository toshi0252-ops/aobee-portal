# P2 あおびーRPG 序盤案内の親切化（2026-11-12）

対象: `games/rpg/`（index.html / style.css / src/app.js / src/events.js / src/ui.js）
監査P2「牧場・RPG・神殿の序盤案内の親切化」のうちRPG分。実プレイ診断（2026-11-12、本番版）で確定した所見に基づく。

## 診断で確定した問題
- 話しかけ判定そのものは緩い（向き不問・上下左右の隣接で会話可能。コード上も `app.near()` が向き不問の隣接フォールバックを持つ）。にもかかわらず「シビア」と感じる原因は、**届く範囲に入ったことが画面で分からない**ことだった。
- 対象が範囲内かを示す `#interaction-hint` は存在するが、小さく右下隅にあり、相手の名前だけが表示されるため「名前札」に見え、「今なら話せる合図」と気づきにくい。ボタン側の見た目は範囲内外で変化しない。
- 話しかけ方の説明は「設定・遊び方」の操作欄にしかなく、初回フローでは表示されない。失敗時のトーストも「少し近づいて」と言うだけで、届く目安が分からない。

## 修正内容（案内の視認性のみ。判定・会話・移動ロジックは無変更）
1. **範囲内サインの強調**（src/app.js / style.css）: 対象が範囲内の間、ヒントラベルを金色背景にして、右下の「話す／調べる」ボタンにパルスの光彩を付ける（`.ready` クラスを毎フレームの既存ヒント更新に合わせて付け外し）。ヒント文も、NPCのときは「（名前）と話す」と表示して合図だと分かるようにした（オブジェクト側の従来文言は維持）。
2. **序章完了トースト**（src/events.js）: 既存の「旅の手帳に、おつかいを記しました。」に「人の隣に立つと、右下の「話す」ボタンが光ります。」を続けて、自由移動が始まるタイミングで一度だけ教える。
3. **失敗時トースト**（src/events.js）: 「少し近づいて、話す・調べるを押してね。」→「もう少し近づいてみて。相手の隣に立つと、右下のボタンが光るよ。」に変更し、失敗した瞬間に目安を教える。
4. **設定・遊び方**（src/ui.js）: 操作説明に「相手の隣に立つと、右下のボタンが光ります。」を追記。
5. **キャッシュバスター**（index.html）: 変更した style.css / ui.js を guide1→guide2 に更新し、events.js / app.js にも ?v=guide2 を付与。

## 直していないもの
- 話しかけ判定（隣接条件そのもの）は変更していない。診断の結論が「判定ではなく見え方の問題」だったため。
- 序盤に自機（青い犬）とルミナを取り違えやすい点は診断で挙がったが、演出・描画の変更になるため本PRの対象外。
