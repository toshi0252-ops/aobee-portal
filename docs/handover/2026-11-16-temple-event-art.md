# 第1章 イベント一枚絵

壁画を調べる会話と、長老への報告・帰還祝いの会話に横長の一枚絵を追加。
`CHARACTER_GUIDE.md` と公式 `assets/characters/aobee-front-v1.png` を確認して制作。

- `assets/temple-events/ch1-mural.webp`：種・芽・花の壁画とあおびー。
- `assets/temple-events/ch1-homecoming.webp`：灯りの戻った村の小さな帰還祝い。
- 原画は内蔵画像生成で制作。プロンプトの要点：公式デザインを維持し、青と金の地下遺跡／紺と琥珀色の夜の村を、緻密なピクセル調の背景で描く。画像内の文字や操作ボタンはなし。
- 会話に任意の画像キーを渡す。既存の会話停止・決定入力・終了コールバックを使用し、新しいセーブ項目は追加しない。
- 待機中の会話にも画像キーを保持。通常会話へ戻ると一枚絵を非表示にする。
- 読み込み失敗時は絵を非表示にし会話は続行。遅れて画像を読み込んでも終了した場面を再表示しない。
- WebPを会話時に読み込み、ゲーム本体に画像データを埋め込まない。
- ポータルのリンクに新しいキャッシュ識別子を設定。

検証：`node tests/temple-event-art.cjs`、`node tests/temple-chapter5-flow.cjs`、`node tests/temple-keyboard.cjs`。全5章の進行・保存復帰・クリア後探索、画像の2か所の起動、会話待ち行列、読み込み遅延・失敗を確認。

スマホの実際の表示とタッチ操作は未検証。
