# 2026-11-19 玲奈: 詳細地図・休み火・回復薬

## 遊び方
- メニュー「詳しい旅の地図」、または従来の旅の地図の「詳しい地図・訪問記録」から開く。
- 全38地点を地域ごとのつながりで表示。地図は上下左右にスワイプ可能。現在地、訪問数、ハート取得数、地点ごとの未回収ハートと休み火登録を確認できる。
- 到達済みの地点を選んで「この場所へ戻る」。未探索地点は移動不可。進行、装備、HP、収集品を維持し、安全な入口付近へ移動する。
- 「案内先にする」は訪問済み地点への寄り道用。地点移動時に次の道を短く案内し、到着時に解除。メイン目的は上書きしない。
- 村、深緑の森の広場、港、島の集落、神殿の庭、星渡りの工房に休み火。隣で火を向いて「調べる」。休むと最大HPまで回復し自動セーブ。手動3枠は変更しない。
- 休み火では星片2で回復薬1個を補給、所持5個まで。保存失敗時は購入取消・星片返却。
- メニュー「回復薬を使う（所持数）」でHP1回復。満タン・薬なしの場合は消費しない。戦闘画面の常設ボタンは増やしていない。

## セーブ互換
chronicle.version=1 に visited/camps/pin を追加。旧セーブはクリア章と各章の実績から訪問記録を推定し、現在地を登録。新形式は訪問記録のみを採用し未探索解禁を防止。未知のID・重複・不正な案内先は復元時に除外。描画からセーブ状態を変更しない。

## 実装
assets/temple-chronicle.js を既存の Mobile 後に追加。クエスト在庫に検証つき grant、Combat.grantShards に購入取消用の無演出返却を追加。HTML、Recovery、portal/index のキャッシュ識別を chronicle-20261119 に更新。HTML marker は chronicle-v13。
