# 連携資料: GRAND PRIX コースアウト復帰支援（2026-11-08、Muse）

## 経緯（大事な訂正を含む）

遊戯監査（2026-11-08）の初回報告で「GRAND PRIX は3D画面にコースが描画されず、ゲームとして成立していない（P0）」としたが、**これは誤診だった**。同日の再検証とコード精読で以下を確認済み:

- スタート直後: チェッカーのスタートライン、灰色のアスファルト、赤白の縁石、アイテムボックスが正常表示
- 走行中: 画面いっぱいに道路と縁石・白線が表示され、コースは明瞭
- ミニマップ: コースのループ輪郭とレーサーのドットが正常表示・更新
- コード側も paintMap → map32 → 床キャスター描画、車の初期配置（road[0]）、カメラ更新まで一貫して正常

初回報告の「一面の緑」は、検証カートが最初の右カーブでコースアウトした後の状態だった。

## 真の問題（今回の修正対象）

草原（meadow）コースにはコースアウト後の復帰手段がない:

- 落下→復帰（updateFall）は海岸・星空コースのみ。草原では際限なく草原を走れる
- 3D画面に道路の方向を示す手がかりがなく、復帰が困難（ミニマップはあるが小さい）
- コースアウト中、自機ドットがミニマップの枠外にはみ出して見えなくなる
- 軽微: DOMの速度表示（#top）が TIME タイルの下端と重なって切れる

初見プレイヤーが最初のカーブで詰む構造のため、深刻度は P0 のまま据え置き、監査レポート側も訂正済み。

## 変更内容（games/aobee_grand_prix_v47_visual_lobby.html）

1. **誘導矢印（drawOverlay）**: コース中心線から 62 ユニット超離れたら、画面上部中央に「最寄りのコース地点への相対方位を示す矢印バッジ＋『コースはこっち！』」を表示。方位は road[car.idx] への角度 − 車の向きで算出。
2. **復帰手段 respawnToRoad()**: 落下復帰（updateFall）と同一定式で、最寄りの道路地点へ車を戻す（向き＝進行方向、初速 42、sideSlip/spin リセット）。呼び出しは2系統:
   - PC: **R キー**（keydown ハンドラに追加。VS/オンラインでは無効）
   - タッチ: **「↩ コースにもどる」ボタン**（新規 DOM #respawnBtn。コースアウト中だけ updateHud が表示。VSでは非表示、オンラインでは表示しない）
3. **ミニマップの自機ドットを枠内にクランプ**: mx/my を [474,620]×[56,183] に制限し、枠外でも端に留まって方角が分かるようにした（ライバルは常時コース上なので対象外）。
4. **速度表示の重なり解消**: #top の top を 66px → 84px（HUDタイル下端との衝突回避）。
5. **遊び方テキストに追記**: 導入文と「操作・あそび方」の2か所に「R コースに復帰」を追加。

ラッパー（games/aobee_grand_prix_v41_portal.html）はキャッシュバストのため iframe の `?v=v47b` → `?v=v47c` に更新。

## 対象外（意図的に触っていない）

- VS（2人対戦）・オンライン対戦での復帰支援: 状態同期と相手側表示の設計が要るため別課題。現状は従来どおり復帰手段なし（悪化はしていない）。
- コースアウト時の減速・芝生摩擦などの物理は無変更。
- 描画系（paintMap / renderGround / カメラ）は無変更（正常と確認済みのため）。

## 検証

- 編集後ファイルのインラインスクリプトを node --check で構文検証済み。
- プレビュー（raw.githack 経由のブランチ版）で実プレイ確認: スタート表示、コースアウト→矢印表示、Rキー/ボタン復帰、ミニマップのドット留まり、速度表示の分離を確認する（結果は PR に追記）。
