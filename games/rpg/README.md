# あおびーRPG ～星を忘れた世界～ v0.12.2

序章「ふたりの約束」から最終章「何度でも、星を灯そう」の結末まで遊べる、新規制作のブラウザ2D RPG。

## 遊ぶ
配布用 aobee_rpg_final_v122.html は、画像・音・CSS・JavaScriptを内蔵した単体HTMLです。PCはブラウザで開けます。スマホはHTMLを実行できるブラウザで開くかWeb配信してください。ソース版は node serve.cjs で配信し、http://127.0.0.1:8765/ を開きます。

PC：矢印/WASDで移動、Enter/Spaceで決定、Mでメニュー、Escapeで戻る。スマホ：仮想スティック／タップ移動を設定で切替。NPCや調査ポイントのタップ、旅の手帳の道案内で隣まで歩きます。

## v0.6.2の内容
任意の依頼2つ、森の種と落ちた枝の採集、泉の宝箱、攻撃+2・守備+2・最大MP+6のお守りを追加。メニューでお守り交換と探索中のほし草使用ができます。任意依頼は旅の手帳に表示。モコ1体はため攻撃、2体は防御と仲間の回復を使います。既存の物語と旧セーブから継続できます。

リーフィ加入後、封印解除までの森で、歩行距離によるまよいモコ1体・2体のランダム戦闘。24〜38歩の遭遇間隔（調査点近くは数えない）、戦闘後の猶予、経験値12/20とほし草1つ。泉の岸辺は何度でも無料でHP・MPを回復でき、旅の手帳から案内できます。守護獣の攻撃を通常13→10、咆哮18→14に軽減。HP140と30％の鎮静条件を維持し、旧ボス戦セーブも再開できます。

v0.5.0の石碑終了記録から、泉の東にある「星の祠へ」を調べると続きます。岸辺の休息は回復用として残しています。

わるびーが小鳥を救う幕間、祠での警告、メモリアビースト戦、リーフィの鎮静、三つの輪を回す封印装置、森の記憶回復、セレナの名前、村への帰還、アストラの幕間を追加。第1章ではわるびーとは戦いません。

守護獣はHP30％以下（42/140）でリーフィの子守歌が届きます。HP0でも通常撃破にはせず、鎮静の場面へ進みます。3ターンごとに全体への星の咆哮。予告が出たら防御を。HP0での鎮静は追加のMPを必要としません。退却と全滅は再挑戦可能。全滅時はHP・MPを回復します。

封印装置は左・中央・右の輪を個別に調べ、種・芽・花をそろえて中央を操作。手帳に現在の絵と道案内を表示します。合わないときは進行せず、手がかりを表示。輪の途中状態も保存します。

解除後は、プレイヤーが戻った森を歩きます。泉でリーフィの名前の記憶を聞き、村へ帰ります。小鳥・鹿・リボン・村人への寄り道は任意。章完了後も村や森を歩けます。

## 保存と更新
localStorageの3スロット、JSON書き出し／読み込み。ブラウザ・配信元ごとに別の記録です。更新に備えてJSONを保管できます。セーブ形式v3を継続し、v1・v2も読み込み時に移行。既存の位置・所持品・選択・進行を保持します。

戦闘のコマンド選択時と結果画面、演出の区切りで保存できます。敵・仲間HP/MP、手番、防御、道具、履歴、結果、演出のstep、封印装置を記録。報酬は結果確定時に一度だけ受け取り、守護獣の鎮静を重複させません。破損した記録は上書きせず拒否します。前版HTMLとZIPは別ファイルで保持。

## 素材と構造
あおびーの歩行画像は前版で使用していた公式設定に基づく派生素材を継続使用。元設定画のピクセル一致の切り抜きではありません。ルミナは許可された新規デザイン。リーフィ・モコ・守護獣は本作用のオリジナル画像。わるびーはあおびーの画像を同種族の参考として制作した別キャラクターです。地形・家具・鹿・装置はCanvas描画。BGM・効果音はWeb Audioの本作用オリジナル。

描画／入力／マップ／会話・UI／章進行／演出／戦闘計算／戦闘UI／保存を分離。src/chapter1-finale.jsに後半の進行・会話・演出・保存メタデータを配置。戦闘はencounters定義でモコと守護獣を登録。node pack.cjsで単体HTMLを再生成。画像は各1回だけ内蔵します。

検証は tests/ 内の19種類の .cjs。詳細は docs/chapter1.md・docs/chapter2.md・docs/validation.md。実機のタッチ感・音量・物語の間の最終確認は、としのプレイで調整します。

## v0.12.1 世界の方向と仲間表示の修正
西の港へは村から左へ出て、街道を左へ進み、港の東側に到着。帰りは右へ進む。夕焼けの丘は村の南から入り、北側の道で帰る。画面左上に北・西・東を表示。村・街道・港・丘の相互移動では、到着地点に出入口から2マス以上の余裕を確保。

一時加入を含む仲間は固定NPCから外し、控え・ルミナも含めて同行表示に統一。過去の会話場所は足跡の調査ポイントとして維持し、イベントと道案内を継続。見送りや再会などの演出には必要な登場人物を表示する。

室内出口の誤った「村へ」表示、長い地名とメニューの重なり、再会後の不在の痕跡、古い未実装案内、章を進めると港の任意依頼が手帳から消える問題も修正。
