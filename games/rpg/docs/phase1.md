## 設計上の整理
- 星形ペンダントはルミナの大事なもの。あおびーの既存の歯車ペンダントと別アイテムIDで管理。
- 夕焼けの選択は `choices.sunsetPromise` に保存し、将来の章から参照。フェーズ1では選択イベントを先取りしない。
- ルミナの導入会話は独立したイベントIDを持つ。初回完了後の通常会話を別にし、ロードで初回会話を重複させない。
- 会話、メニュー、マップ切替中はフィールド入力を無効化。キーとポインター状態は画面切替・フォーカス喪失時に解除。
- タップ移動は歩行可能タイル上の幅優先探索。NPCや入口では隣接地点へ移動して調べる。仮想スティックと切り替え可能。
- PCは矢印/WASD、決定Enter/Space、戻るEscape。スマホは安全領域を確保し、操作ボタンは44px以上。
- マップは表示タイルと衝突データを分離。画面には周辺タイルだけ描画し、devicePixelRatioは上限2。
- 戦闘は未実装表示。ステータスは初期値、装備は現在の装備確認のみ。買い物や交換を完成済みに見せない。
- BGM/SEは個別設定。音源はオリジナルを制作し、ブラウザのユーザー操作後に開始。
- セーブは安定したIDとバージョンを保存。未来バージョンを誤読しない。破損時はエラーを表示して元データを保持。
- ブラウザ保存は同じブラウザ・同じ配信元に依存する。公開URL変更時の引継ぎに備え、JSONエクスポート/インポートを実装。

## モジュール
`renderer` 描画 / `maps` 衝突・入口 / `events` 一回限りのイベント / `dialogue` 文字送り・履歴 / `battle` 後続フェーズ / `characters` 最大4人 / `items` 安定ID / `save` 移行・保存 / `ui` メニュー・戻る / `input` 操作 / `audio` 音量。
