# 最終章「何度でも、星を灯そう」v0.12.0

第5章の同期完了後、黒い星の城・観測室東の「星の深淵へ」から継続。旧セーブ形式v3を維持し、追加フィールドがないデータも読み込める。

## 実装

- EV601〜614、星の深淵7区画、区画ごとの無料休憩と記録、到達済みの区画へ入口から直行する帰路。
- 回廊の供給経路3つは自由な順番で修理。湖の5人の断片も自由順。庭の石碑から次の修復へ進む。
- 修復は物理接続→解析→生命循環→回収封印→星光安定化→同期の6作業。控えも参加し、ルミナは非戦闘支援を維持。
- ガーディアンはHP360、物理／星・闇耐性を毎ターン切替。偶数ターンに封印、3ターンごと全体攻撃。解析・解除・防御・かばうを利用可能。
- コアはHP420、通常攻撃ではHP1で止まる。2ターン目から専用「制御端末」コマンド。解析→再接続→権限取得の後、HP126以下で再生停止→環境維持へ切替。操作は1人の行動を使用、控えも支援。とくぎの封印では装置操作を阻害しない。退却・敗北では全回復し端末は再試行。
- 最後の説明後に「みんなを信じて進む」「もう一度、準備を確認する」。後者では通常フィールドに戻り、装備・編成・セーブ・各地の寄り道を利用してから再開できる。
- 記憶結晶は既存の記録だけを再生。終盤の退避はガルド・ミラ・ルミナの共同開発による新規記録で、完全保存を保証しない。
- 序章の `choices.sunsetPromise` を目覚めの会話で参照。remember／againは会話のみの差で、世界救済の結果は同じ。
- 核から村へ仲間が運んだ経緯を明示。各地の便りと情景、夕焼けの丘、クレジットを経て `gameClear`／`chapter6Complete` を保存。セーブ画面に「物語クリア」を表示。
- 結末の再発火とボスの再出現を防止。クリア後も各地の探索と旧章の未完了依頼を継続。
- 新しいアストラは星形の機械としてSVGで制作し、フィールド／戦闘で共有。公式あおびーと既存仲間の画像は維持。

## 検証

`node tests/chapter6.cjs` で実マップの経路を通った16通り（約束2通り×スキップ有無×控え4人）の全行程、87演出地点のセーブ移行／再開、通常能力・所持品での2ボス、制御端末の順序制約、HP1、準備後の城への帰還／核への再入場、旧章のお守り・任意進行維持、敗北／退却、重複報酬防止、3スロットのクリア記録を確認。21本の旧テストも実行。

単体HTMLの32スクリプトと埋め込み画像、ブラウザでの読み込み順を確認。スマホ幅390×844でコア戦復元・4人の防御・端末出現・解析・戻る、最後の準備確認を操作検証。実機スマホと120〜150分の所要時間は未確認。バランスの最終監修はとしのプレイ感を反映する段階。

## 修正した既存の問題

第2章のセーブ検証に出撃ガルド必須の条件が残っていたため、第4章以降の自由編成でガルドを控えにした記録が読み込めなかった。わるびー加入後はガルドの同行データを確認し、出撃枠は自由にした。夕焼けの丘が旧章の道案内グラフに含まれていなかったため、村との往復を追加した。
