# 序章実装 v0.3.0

描画・マップ・操作・会話・イベント・保存に加え、src/story.jsで章段階、目標、NPC表示、道案内データを分離。

進行ID: morning → search → sunset → night → missing → elder → depart → complete。eventsに段階と各達成フラグ、choices.sunsetPromiseにremember / again、keyItemsにluminaPendantを保存。段階は会話完了時に更新。おつかいの報酬・所持品消費は各一度のみ。

朝のおつかい: 村長の本（家の書棚）、噴水の水→花守り、箱のほし草→ルミナ。2件を終えルミナに報告すると森へ。ペンダント発見後は村の南から丘へ。約束後、ルミナの家のベッドで夜を迎える。翌朝は広場のいつもの場所と家のふたつのカップを調べ、村人へ話し、日記を読む。そこから村長へ。以前の版で忘却会話を済ませたセーブは探索の前提を満たした扱いとする。村南東の森入口で序章を完了。

約束の選択画面は戻って選び直すことができ、選択確定で物語を進める。完了後は村を探索・セーブ可能。第1章は未実装。導入・会話途中の手動保存は不可。フィールド、または演出の「メニュー・戻る」から保存する。演出はevents.cinematicのidとstepにより再開。場面の待ち時間は再開時に最初から。

v1→v2はコピー上で移行し、既存ブラウザ記録を自動で上書きしない。マップ/所持品/設定/訪問フラグは継承。既存の開始会話は再生しない。新規物語は朝のおつかいから進める。

src/scenes.jsで場面定義と再生処理を分離。表示用の座標は実際の保存座標を動かさず、完了時に安全な位置へ確定。約束は選択時、ペンダントは丘の場面完了時に記録。光の糸、湯気、景色、明暗はCanvas描画。OSの動きを減らす設定では座標補間を省略。
