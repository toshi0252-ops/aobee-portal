# v0.12.1 方向・同行キャラ・再訪の修正

## 原因と修正

西の港への街道が、村側の入口を左、港側の入口を右に配置していた。街道の港側を左へ、村側を右へ移動し、港の街道出口も東側へ変更。往路は左向き、帰路は右向きで到着する。北を上に固定する表示をHUDに追加し、道標と案内板の矢印を一致させた。夕焼けの丘は村の南にあるため、丘の北側から入り、北へ帰るよう配置と入口の道を調整。

仲間のNPC配置には加入後の除去処理がないマップがあり、リーフィが複数の森マップに残り、ガルドとミラも部屋へ戻ると固定NPCとして現れた。`party-field.js` で同行者を一元的に判定し、一時加入と控えも含めて固定NPCを除去。現在のフィールドで歩いた道をたどる表示に統一。マップ切替・ロード・編成変更で足跡をリセットし、壁・水・出口・主人公と同じ座標を避ける。視覚上の隊列は主人公の移動を妨げない。イベントの登場人物と同行表示が重なる場面では、演出の配置を優先。

リーフィの子守歌・泉の会話など、NPCへの接触が必要だったイベントは足跡の調査ポイントへ引き継ぐ。会話の発火と道案内のIDを保ち、各章の進行を変えない。再会前や加入前の人物は必要な場所に表示する。

## テストプレイで確認した追加修正

- 村・街道・港・丘の相互移動で出口の隣に到着し、戻る操作になりやすかったため、2マス以上の距離を確保。
- クロノアなどの室内出口にも「村へ」と表示されていたため「出口」に修正。
- 長い地名がメニューや目標に重なるため、HUDを省略表示にして幅を制限。正式名は手帳・マップのアクセシビリティ名・タイトル属性で確認可能。
- 案内板の幅を文字列に合わせ、行き先と矢印が板からはみ出す問題を修正。
- ルミナ再会後も村に不在の痕跡が追加されていたため、再会後は出さない。日記の会話も隣にいるルミナへつながる内容へ変更。
- 既に完成した章の「未実装」「次の制作範囲」という古い案内文を更新。
- 第3章以降の手帳から港の任意依頼「船の目印」が消えていたため、後の章にも引き継いで表示。

## 検証範囲

23本のNode検証が成功。新しい `world-consistency.cjs` は村→街道→港と帰路の実イベント呼出し、移動経路の向き、丘の南北接続、旧セーブの座標互換、全マップで加入済み固定NPCがいないこと、調査地点への到達、歩行中の主人公との重複防止、隊列リセット、10マップとクリア後の描画で各同行キャラが1回だけ描画されること、エンディングの演出配置との重複防止を確認。

全章の既存テストで、会話・加入・戦闘・寄り道・最終選択・2種類の結末・クリア後探索・保存を再検証。ブラウザでは西向きの実移動と港への到着、加入後の工房への再訪、調査地点の会話、室内からの退出、スマホ幅とPC幅を確認。実機スマホのテストは未実施。

セーブ形式v3と既存の所持品・レベル・装備・選択・進行フラグを維持。旧v0.12.0のHTMLとDriveファイルは残し、v0.12.1を別ファイルで配布。
