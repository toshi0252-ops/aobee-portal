# 第1章・入口と初戦 v0.4.0

## イベント
prologueStage=completeを入口条件とし、chapter1Stageをbird→trail→leafy→battle→clearedへ進める。新しいmemory-woodsマップで進行し、既存マップの移動位置を変更しない。森への入口は、旧forest-edgeからも利用できる。
forestArrivalで導入を一度だけ表示。forestSuppliesでほし草3つの配布を一度だけ行う。mocoClearedで報酬の重複と同じ戦闘の再開始を防ぐ。リーフィはcharactersに登録するが、partyへの正式加入は鹿のイベントまで行わない。

## 戦闘
battle-core.jsは入力スナップショットを複製し、検証済みコマンドを1つ適用。最後の仲間が行動すると敵ターンをまとめて計算し、安全な次のコマンド境界へ進める。失敗したコマンドはHP・MP・道具を変更しない。
battle-ui.jsは結果の演出を順に表示。計算結果を確定してから演出し、演出中は操作を受け付けない。演出の中断で報酬を二重に発行しない。タイトル・ロード・新規開始時はタイマーを解除し、世代番号で古いコールバックを無効化する。
勝利報酬は結果画面から探索へ戻る時に確定。結果画面のセーブも復元可能。逃走は消費済み資源を保持し、全滅はHP・MPを回復。瀕死・戦闘不能の仲間がいる再挑戦では、生存者から行動を開始する。
経験値は次のレベルまでlevel×24。レベルごとに最大HP+6、最大MP+3、攻撃+2、防御+1。この初戦でLv.2になる。

## UIと保存
戦闘速度1〜3を設定に追加。対象選択・とくぎ・道具・逃走確認・説明の各ページは戻る/Escapeでコマンドへ戻れる。戦闘のメニューでは手帳の道案内を無効にする。
形式v3で戦闘の数値・敵ID・手番・結果と章進行の整合性を検証。v1/v2は移行可能。JSONの記録読込をブラウザQAに使用し、アプリ内部へのテスト用コード注入は行わない。

## 次の制作
鹿と子守歌のフィールドイベント、リーフィ正式加入、森の拡張へ。三つの石碑は独立した後続パズルとして残す。わるびーとの戦闘は作らない。守護獣はHP30%以下またはHP0で鎮静化イベントへ進める予定で、この版には未搭載。

## v0.5.0 記憶の泉まで

進行: bird → trail → leafy → battle → cleared → deer → soothe → spring → stones → shrineTrail。前版のclearedはリーフィの休息から継続できる。forestClosingSeenが旧版でtrueでも新しい進行を阻害しない。

新しい探索マップはdeer-hollowとmemory-spring。道案内は森→くぼ地→泉の接続をたどり、戻りの入口も機能する。新しい調査ポイントと目的を手帳に明示。リボンと蹄の跡は任意の背景情報で、必須進行条件にしない。

鹿の観察でsootheへ。soft-leavesからleafBed演出を完了するとdeerBedがtrue。そこでリーフィへの依頼を受け付け、deerSong完了時にdeerCalmedとleafyJoinedを確定し、partyへ重複なく加入させる。フィールドの子守歌は物語イベントでMPを消費しない。

泉の反応後に石碑を調査。seed-stone → sprout-stone → flower-stone。間違えた場合は0へ戻し、種からやり直す説明を表示。stoneStepは0〜3、途中の順序を保存する。三つ目の点灯ではstonePathの完了まで演出記録を保持。森全体の記憶回復とは区別し、祠への道の手がかりだけを開く。

新規の11演出は会話と手動で進める視覚的な間を交互に配置。各チェックポイントはマップ・章進行・step数を保存時に検証。mocoApproach完了ではbattle.startが設定したbattleモードを保持するよう演出終了処理を修正。泉の岸辺の休息はHP・MPを回復し、実装範囲と保存方法を表示する。

未実装: わるびーの小鳥救出、祠での警告、守護獣、封印解除、セレナの名前、帰還、アストラ幕間。旧章仕様は上記追加によって更新される。

## v0.6.0 第1章後半

src/chapter1-finale.jsに後半の進行と演出を分離。旧shrineTrailから祠の入口を調べると、わるびーの小鳥救出を見てwarningへ。警告の完了後にbeast。わるびーとの戦闘は存在しない。

戦闘はencountersにmoco-tutorialとmemoria-beastを登録。守護獣はHP140、HP42以下で子守歌からcalmedへ。HP0もcalmedへ進む。wonを返すのはモコのみ。3ターンごとの星の咆哮は全体攻撃で、ターン開始時に予告し、防御で半減。睡眠は咆哮も1ターン止める。退却・全滅ではbeastを維持し、全滅は全回復。calmedの結果確定で48経験値、HP/MP回復、beastSubdued、calmingを一度だけ設定。guardianSong完了でbossCalmed、sealへ。

封印装置はsealRings（各0種/1芽/2花、初期2/0/1）を各輪への調査で循環。手帳に現値と各輪への案内を表示。0/1/2を中央台で確定するとforestReturn演出。終了でforestRecovered、recoveredへ。水・草・音・NPCの言葉が変わる。泉のリーフィからセレナの記憶を聞くとreturning。鹿や小鳥への寄り道は任意。村の入口でhomecoming、村長の報告からchapterCompleteとastra。夕焼けの約束は帰還時の台詞で回収。全完了後も探索と保存を継続できる。

保存は後半のsceneSpecsからマップ・進行・step上限を受け取り、旧v1/v2/v3を読み込む。ボスの戦闘はstar-shrine/beastの記録として検証し、守護獣・封印・セレナ・章完了の前提を照合。途中の輪と演出のcheckpointを保持。第2章、ランダム遭遇、装備交換、4人戦闘は未実装。

## v0.6.1 雑魚戦・準備・難易度

src/encounters.jsに歩行による遭遇判定を分離。リーフィ正式加入後、封印解除までの3森マップで稼働。NPCと調査点からマンハッタン距離3以内は歩数を消費しない。イベント・会話・メニューではfield更新が停止し、祠と回復した森では遭遇しない。残り歩数・32bit乱数の種を保存し、復元による遭遇の即時連発を防ぐ。戦闘終了後は24〜38歩の猶予。seedに基づき1体HP22または2体各HP20を選ぶ。

雑魚の通常攻撃6、経験値12/20、ほし草1つ。勝利しても章進行・イベント戦のフラグを更新しない。結果確定後のbattle削除で重複報酬を防ぐ。逃走と全滅も物語を進めず、全滅は全回復。戦闘途中保存はプロフィールと地図・加入の前提を検証。

泉のspring-restは正式加入後に繰り返し全回復可能。初回の岸辺イベントは従来通り保持。旅の手帳から回復ポイントへの道案内を提供。守護獣の通常攻撃13→10、全体咆哮18→14、HP140と30％条件を維持しv0.6.0のボス戦セーブに対応。祠の警告後にくぼ地から泉へ戻れない従来のステージ制限も修正。

## v0.6.2 寄り道・道具・お守り

任意の依頼「花壇へ帰る種」「小鳥の止まり木」を追加。花守りミナに森の種3つを届けると若葉のお守り（守備+2）とほし草2つ。リーフィ加入後、小鳥のために落ちた枝を運ぶと星かけらのお守り（攻撃+2）。泉の木の根元の宝箱から朝露のお守り（最大MP+6）。採集は受注前でも可能、各報酬は一度だけ。主筋のイベント条件は増やさない。

src/adventure.jsに任意依頼、採集、お守り、探索中の道具使用を分離。お守りは仲間1人につき1つ、同じ品の二重装備は禁止。公式のリボンを残し、キャラクターの外見は変えない。装備変更時はHP・MPを上限へ丸めるだけで回復しない。泉・レベルアップ・敗北時の回復、戦闘の能力値、ステータス、セーブ検証へ装備補正を反映。探索メニューからほし草でHP20回復・蘇生でき、戦闘や演出の途中は使用・交換を抑止。

モコ1体は力をため、次の体当たりが強くなる。モコ2体ではAが奇数ターンに防御、Bが偶数ターンに生きている仲間を6回復。星のひかりはモコの防御を通る。睡眠はためた力を保ったまま敵の手番を止める。braced/chargedは保存し、旧チェックポイントには未設定も許容。チュートリアルと守護獣の行動は変更しない。

採集と新宝箱は通行可能な調査点として追加し、旧セーブの位置を塞がない。旅の手帳には任意の依頼の進行と道案内を表示。gear/sidequests未設定の旧セーブは空の一覧へ移行し、所有・二重装備・採集・依頼完了の整合を検証。
