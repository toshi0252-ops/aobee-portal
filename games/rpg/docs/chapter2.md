# 第2章「忘れられた息子」v0.7.0

企画・シナリオ：葵（Ver.1.0）／開発：玲奈／最終監修：とし。

## 構造
chapter2.js に個別イベント、69ステップの演出定義、段階・フラグ検証、手帳、章間道案内。chapter2-maps.js に10マップ。戦闘コアの章2プロファイルのみ3人編成。章1の2人戦闘は維持。セーブ形式3の拡張として新フラグ・仲間を保存し、旧記録から開始可能。

## 手順と解釈
EV204は仮調査許可、EV205救助後に正式許可。かばうは全体攻撃を肩代わりしない。制御修理はMP4・2敵ターン停止・戦闘ごと2回。洞窟の流木は潮が低い時だけ通行可。工房の実験が必須、以後は昇降機と通常入口で上層へ。わるびーHP40％以下なら撤退、ゼロでも死亡しない。ボス戦後、制御盤への手動操作が必須。エマの記憶を完全回復するフラグを設けていない。約束2択は母の時計の会話で回収。EV201〜213を個別保存し、既に完了したイベントへ戻らない。

## 検証
tests/chapter2.cjs はテスト内で章1クリア記録を構成し、全イベントを実際のコア操作で進行。69演出ステップの保存・再開、双方の約束、信号失敗・成功、潮位衝突、修理、結晶実験、自然な戦闘、40％/HP0撤退、全滅/逃走後の再挑戦、制御装置、母の時計、正式加入、村への帰還を検証。QA JSONはこの進行から生成しリリースZIPに含めない。マップ試験は洞窟を低潮・流木固定後に解決し、閉潮は章2試験で別検証。自動経路は目的地以外の玄関を避ける。
