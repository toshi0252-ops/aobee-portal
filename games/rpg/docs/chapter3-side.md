# v0.9.1 クロノアの寄り道

src/chapter3-side.jsに依頼データ、任意進行、手帳目標、調査点、保存検証を分離。EV301以降に開放し、主筋のEV・章ステージ・加入を変更しない。events.c3Side内に記録し旧セーブは未受注として扱う。最大4人編成と保存形式v3を維持。新しいお守りは既存の装備／戦闘能力計算を使用。

職人：商業区の作業着の人から受注→研究区の工具と広場の継ぎ目（順不問）→報告。時計：商業区の時計職人から受注→広場の小時計の低→高→中を調査→報告。失敗で音順のみリセット、手動リセットあり。便り：駅の郵便係から受注→駅・広場・研究区の封書（順不問）→報告。受注前の調査は依頼主を案内し収集しない。完了後も会話できる。

品質区分：任意依頼3件の初期実装。NPCは既存住民の描画。録音音声や専用演出カットは未制作。音の順番は文字で操作でき、消音でも解ける。実機の操作感と寄り道時間は未測定。
