# 1. 基本コンセプト

本編クリア後、ステラリアは世界再生の危機を脱した。

しかし、世界が救われても、失われた記憶がすべて戻るわけではない。

セレナはリーフィと過ごした日々を完全には思い出せず、エマはガルドを息子だと認識できない。オルフェが残した研究も、消された年月を取り戻すことはできない。

それでも、人々は新しい関係を築き始める。

**クリア後のテーマ：「思い出は、これからも作れる」**

### 基本ルール

- 本編クリア後の自由探索から開始可能。
- 重要イベントは期間限定にしない。
- クエストの受注順序は原則自由。
- 取り返しのつかない選択肢は作らない。
- 仲間の後日談と地域復興は相互に関連させるが、進行不能になる依存関係は作らない。
- 過去の記憶は記録・手紙・写真などで知ることはできても、本人の記憶が自動回復することはない。
- 完了後は町並み・住民の配置・会話・BGMの一部などに恒久的な変化を残す。
- 旅の手帳に発見した記録、完了イベント、地域復興状況を保存する。

## EX101「ふたつめの子守歌」
### 主役：リーフィ／セレナ
### 舞台：ほしの森・記憶の泉

**開始条件**
- 本編クリア済み。
- ほしの森でセレナに話しかける。

**導入**

森に平和が戻ったものの、セレナは昔の子守歌を最後まで歌えない。

リーフィは、かつて教わった歌を歌ってみせる。

セレナ「……不思議ね。その歌を聞くと、胸が温かくなるの」

リーフィ「セレナが教えてくれたんだよ！」

セレナ「そう……だったのね。でも、ごめんなさい。まだ思い出せないの」

リーフィは一瞬寂しそうな顔をする。

しかし、あおびーが提案する。

あおびー「だったら、新しい歌を一緒に作ろうよ！」

**探索・作業**
- 森の3か所で自然の音を探す。
- 小鳥のさえずり、泉の水音、木々を渡る風を集める。
- 森の精霊たちに協力を依頼する。
- 記憶の泉で音を組み合わせ、新しい旋律を完成させる。

**クライマックス**

リーフィとセレナが、初めて一緒に新しい歌を歌う。

セレナ「この歌は、私も覚えていられるかしら」

リーフィ「もし忘れちゃったら、また一緒に歌おう！」

セレナ「……ええ。今度は、私たち二人の歌ね」

**結末**
- セレナは過去を思い出さない。
- しかし、リーフィを大切な存在として新しく認識する。
- 二人が定期的に森で歌うようになる。

**世界の変化**
- 記憶の泉の周囲に小さな花が咲く。
- セレナとリーフィの歌唱イベントが追加。
- 森の精霊の会話が更新される。

**物語報酬**
- 旅の手帳「ふたつめの子守歌」
- 森の新しい楽曲の鑑賞解放

## EX102「止まった時計の、その先へ」
### 主役：ガルド／エマ
### 舞台：港町ミナトリア・時計工房

**開始条件**
- 本編クリア済み。
- 港の時計工房を訪れる。

**導入**

エマが古い柱時計を修理しようとしている。

かつてガルドが幼い頃に壊した時計だが、エマにはその記憶がない。

エマ「昔からある時計なの。でも、どうして壊れたのかしらね」

ガルド「……俺が壊した」

エマ「え？」

ガルド「子どもの頃にな」

エマ「……そう。あなたにも、そんな頃があったのね」

ガルドは、それ以上説明しない。

**探索・作業**
- 港の倉庫で古い歯車を探す。
- 潮風で傷んだ部品を修復する。
- 時計の内部機構を組み直す。
- エマとガルドが協力して最後の部品を取り付ける。

**中盤イベント**

作業中、エマはガルドの工具の持ち方を見て言う。

エマ「あなた、私と同じ持ち方をするのね」

ガルド「……そうか」

エマ「誰かに教わったの？」

ガルド「……ああ。昔、腕のいい職人にな」

**クライマックス**

修理した時計が動き始める。

エマ「ガルドさん。よかったら、また手伝いに来てくださらない？」

ガルド「……毎日でも来る」

エマ「ふふ。そんなに来られたら、お給料を払わないとね」

ガルド「……いらん」

**結末**
- エマはガルドが息子だとは思い出さない。
- ガルドは過去を無理に説明せず、工房で新しい時間を重ねる道を選ぶ。
- エマはガルドを信頼できる職人仲間として迎える。

**世界の変化**
- 港の時計台が再び動き始める。
- 時計工房の内装が少しずつ整う。
- ガルドが工房を手伝う日常会話が追加される。

**物語報酬**
- 旅の手帳「止まった時計の、その先へ」
- 工房の新しい利用要素を解放するためのフラグ

## EX103「名前の残らない研究」
### 主役：ミラ／オルフェ
### 舞台：クロノア・研究塔

**開始条件**
- 本編クリア済み。
- 研究塔のミラに話しかける。

**導入**

ミラはオルフェの研究を一般公開する準備をしている。

しかし、古い記録には彼の名前が残っていない。

研究員「著者不明の研究として公開するしかありませんね」

ミラ「……いいえ。先生が残したものだって、私が知ってる」

研究員「でも、証明できる資料が……」

**探索・作業**
- 旧研究室で手書きのノートを探す。
- 機械式記録装置から研究過程を復元する。
- 複数の研究資料を照合する。
- 研究成果の実証実験を行う。

**中盤イベント**

ミラは研究塔の壁に残された文字を発見する。

「未来の研究者へ。私の答えを信じるな。確かめ、疑い、さらに進め」

ミラ「……先生らしいわ」

**クライマックス**

公開発表の場。

ミラ「この研究は、オルフェという研究者が始めました」

研究員「正式な記録には、その名前がありません」

ミラ「ええ。でも、ここに手書きの資料がある。実験結果もある。そして、私は彼から学びました」

ミラ「記録に名前がないからって、存在しなかったことにはならないわ」

**結末**
- オルフェの過去がすべて復元されるわけではない。
- 研究の出所が物理資料と証言に基づいて公開される。
- ミラ自身の新しい研究も始まる。

**世界の変化**
- 研究塔に一般公開エリアが追加。
- 市民や学生が研究資料を見に来る。
- 研究塔の掲示板にオルフェとミラの名前が並ぶ。

**物語報酬**
- 旅の手帳「名前の残らない研究」
- 研究資料の閲覧解放

あおびー「こっちにも植えようよ！」

あおびー「でも、今は植えられるよ？」

わるびー「……そうだな」

花壇が完成する。

あおびー「前と同じじゃなくても、いいんだよね？」

あおびー「じゃあ、今度は二人で、もっとすごい花壇にしよう！」

わるびー「……水のやりすぎだけは、やめろよ」

**世界の変化**

**物語報酬**

# 5. 実装上の重要な条件

### イベント管理
- EX101～EX105、EX201～EX204は独立した完了フラグで管理。
- EX301のみ全9イベント完了を条件とする。
- 同じ人物が複数イベントに登場する場合は、現在の進行状況に応じて自然な台詞へ切り替える。
- 本編の加入イベントと同様に、イベント用NPCが不自然に残り続けないよう、配置・非表示条件を明確にする。

### セーブ・ロード
- 既存の3スロットセーブとの互換性を維持。
- クリア後のイベントフラグ、マップ変化、収集記録を保存。
- 旧セーブデータに追加フラグが存在しない場合は未開始として扱う。
- 完了イベントはロード後も再発生しない。ただし回想・記録閲覧は可能。

### 取り返し防止
- 期間限定イベントなし。
- 必須アイテムの売却・消失は禁止。
- 会話選択による永久的な進行不能なし。
- 重要な資料は後からでも回収できる。
- 一度きりのイベントは旅の手帳から内容を振り返れる。

### 旅の手帳
「仲間のその後」「世界の復興」「新しい記録」の3カテゴリを追加する。

各イベントについて、未発見・進行中・完了の状態を表示する。

### 開発順序
1. 仲間の後日談5件
2. 地域復興4件
3. マップの恒久的変化
4. 旅の手帳との連動
5. お祭りイベント
6. 玲奈設計の星脈の試練・装備やり込み

### 品質基準
クリア後の世界を歩いたプレイヤーが、ただイベントを消化するのではなく、

**「自分が救った世界で、人々が新しい毎日を生きている」**

と感じられることを最優先にする。
