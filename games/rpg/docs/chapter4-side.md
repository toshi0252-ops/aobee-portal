# 第4章の寄り道 v0.10.1

src/chapter4-side.jsに進行、目標、調査点、保存検証を分離。events.c4Sideに保存し、旧v0.10.0は未受注として扱う。EV404で開放。章4のイベントや戦闘・加入の進行は変えない。

花壇：庭園の小さな花壇で受注→荒野の旅道具の箱で水筒→庭園の雨水の樽→花壇。水筒なしでは水を運べない。加入前後で会話を変え、完了後も世話の分担を話す。土のお守り（守備+2・最大MP+2）とほし草2つ。

観測：観測室の地上測定装置で受注→ノート→北レンズ左・南レンズ右→手動測定。ノートとレンズの調査順は自由。誤調整は何度でも直せる、途中状態を保存。測定後は角度を保護。観測のお守り（攻撃+1・最大MP+4）とほし草2つ。単一測定で世界維持の安全を証明したことにはしない。

旅の箱：観測室の箱で受注→庭園の結び紐・回廊のカップ・観測室の地図（順不問）→加入後に箱でわるびーへ確認。加入前も収集・保管できるが報酬は未確定。思い出の品を勝手に処分・修復しない。ふたりのしおり（大事なもの）とほし草3つ。

品質区分：任意依頼3つの初期実装。既存キャラクター画像とCanvasオブジェクトを継続。専用カット・録音音声は未制作。寄り道時間・実機の操作感は未測定。手帳から現在の作業へ道案内。既存の3スロット、JSON保存、最大4人出撃を継続。
