# クリア後「新しい毎日」 / v0.12.2

葵のクリア後追加シナリオ企画書 v1.0を基に、後日談 EX101–105、地域復興 EX201–204、追加エピローグ EX301 を実装。

本編のエンディングは変更しない。既にエンディングの便りで始まっている歌・時計修理・研究公開は、今回その活動を継続して地域へ広げる。記憶が自動的に全回復したことにはしない。

## 遊び方

クリアデータを読み込み、メニュー → 旅の手帳 → 新しい毎日の手帳を開く。後日談と復興は好きな順番で開始でき、各カードの道案内で現地へ進む。画面切替後には再び道案内を押す。

自然音3種・森の反射板3枚・資料室の生活記録4件・祭りの準備5件は自由順。他の組立作業は現場の説明に従い、誤った選択は素材や進行を失わず再試行。必要な材料は売却できる所持品に入れず、イベントの作業記録として保存する。

後日談の終了時には作業完了後に相談場所へ戻る。子守歌のみ、最後の演奏を記憶の泉で行う。手帳は次の作業か報告地点へ案内する。

## 保存と設計

データと処理を `postgame-data.js` / `postgame.js` に分離。追加状態は `events.postgame.EX101` などに `{asked:true,steps:[],done:true}`、花の成長は `events.postGardenVisits`、交易の贈り物は `events.postTradeSupplies`。旧形式 version 3 を維持し、追加項目がない旧セーブは未開始。

演出開始・終了は既存の cinematic 保存方式。全10イベントの各演出には待ち時間と任意の文字送りがあり、途中セーブ・再開・スキップに対応。手帳の回想は報酬を発生させず、記録を読むだけ。追加項目の型・作業の依存関係・完了条件・祭りの解放条件を保存時に検証。
