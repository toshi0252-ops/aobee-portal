# 星の神殿 REMASTER 戦闘試作
既存公開版のファイル、セーブ、ポータルを変更しない独立した検証場。第1章の森をイメージした試験用マップであり、本編マップ・物語の移植は未実施。

- index.html: 入力UIと画面
- src/action-core.js: DOM非依存の連続座標、移動、障害物、扇形判定（共通化候補）
- src/trial-data.js: 試験マップ・敵配置
- src/trial.js: 神殿固有の戦闘ルール、描画、入力接続

公式素材は CHARACTER_GUIDE.md の4×2 atlas を直接参照。左右反転なし。
